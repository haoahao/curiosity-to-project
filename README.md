# 從好奇心到專題（Curiosity to Project）

一套四階段的課堂引導流程，幫助高中生從「不知道要做什麼專題」走到「有一個自己想解決的題目」。

📄 **學生可直接看網頁版**：啟用 GitHub Pages 後，網址會是 `https://YOUR-USERNAME.github.io/curiosity-to-project/`（設定方式見文末「啟用 GitHub Pages」）。

## 為什麼需要這套流程

大部分學生卡關不是因為創意不夠，也不是因為不會用 AI 工具。他們卡在更前面一步：**沒有一個讓自己有情緒反應的具體經驗，可以拿來轉譯成題目。**

2026 年外灘大會 AI Coding 大賽的冠軍是一位 9 歲女孩，她不會寫程式，卻做出了一款完整的互動作品。真正關鍵的不是她會用 AI，而是她先有一段紮實的生活經驗（一場陶藝夏令營），這段經驗本身逼出了「我想把它做成可以玩的東西」的衝動。AI 只是把衝動變成產出——沒有衝動，AI 再強也只是空轉。

這套流程的設計原則就是：**先製造經驗和情緒，再談工具。AI 是鷹架，不是外包。**

## 適合對象

高中資訊科、新科技學程專題課，或任何需要學生自訂題目的課程。

## 四個階段

| 階段 | 檔案 | 目標 | 建議時間 |
|---|---|---|---|
| 1 | [`01-friction-log.md`](01-friction-log.md) | 從抱怨挖需求，不從興趣挖需求 | 1 週（課餘） |
| 2 | [`02-topic-canvas.md`](02-topic-canvas.md) | 把摩擦點轉譯成一句可執行的題目 | 1 堂課 |
| 3 | [`03-ugly-v1-sprint.md`](03-ugly-v1-sprint.md) | 降低「要做得很厲害」的心理門檻，用 AI 快速迭代 | 2-3 堂課 |
| 4 | [`04-near-peer-showcase.md`](04-near-peer-showcase.md) | 用同儕案例當引信，而非天才案例 | 穿插在階段 1-2 之間 |

## 使用方式

- **老師**：建議照順序帶，每份文件開頭都有教師引導語與課堂操作說明。
- **學生**：`templates/` 資料夾裡有你要填寫的表單，`examples/` 資料夾裡有案例參考。
